# Overnight Desk

Static iPhone web shell for Overnight Desk. Plain HTML, CSS, and JavaScript. No server-side code and no secrets in this repository.

## Add to iPhone

1. Open this site in **Safari** (not Chrome).
2. Tap the **Share** button.
3. Choose **Add to Home Screen**.
4. On first open, paste your private desk link once. It stays on the phone.

If the desk feed is not connected yet, the shell still opens and will show an offline notice until a private live-data host is configured.
